Before we close this chapter on Katakana, there's just a few more things to cover that you might be familiar with from learning Hiragana, and that is Katakana's versions of double consonants and long vowels!

  1. Double Consonants and the Small ッ
  2. Long Vowels

Double Consonants and the Small ッ

If you remember from our Hiragana article, Hiragana uses a small っ to create double consonants. This is also the case for Katakana, so there is not much more for you to learn here other than what the small ッ looks like in Katakana. And to do that, we'll have you type out a few example words in Katakana that contain double consonants.

If you're using romaji input, by default your IME should be set to Hiragana. You can switch to Katakana input in two ways:

  • Right click the "A" or "あ" in your taskbar (usually bottom right of the screen) and select "Full-width Katakana."
  • Press ALT+CAPS to change to Katakana input and CTRL+CAPS to switch back to Hiragana input.

Additionally, when typing in Hiragana, you can press the space bar a few times to look for the Katakana conversion or press F7 while the kana is underlined to convert it to Katakana.

Write the word on the left in Katakana in the input on the right. If the input turns green, you wrote the word successfully.

Hopefully you got a good grip on the small ッ for Katakana now. All that's left is to learn about the long vowels in the section below!

Long Vowels

Just like with Hiragana, Katakana also has long vowels. However, instead of extending the last vowel using a vowel character (e.g., like with おばあさん, おじいさん, etc.), Katakana uses a long dash: ー! This character, formally called a "long-vowel mark", functions exactly the same as the Hiragana long vowels, meaning that you extend the sound that comes before it by twice its usual duration. And just like with Hiragana, if you fail to pronounce this extended vowel, you could end up saying an entirely different word.

The long-vowel mark can be written with the "-" key in either Hiragana or Katakana input mode. For direct kana input, such as on a phone, ー is usually located on the keyboard or under わ if using flick input.

Below are a few examples of long vowels in Katakana. There are no exceptions for different vowels like there were with Hiragana, so it's fairly straightforward and easy to remember.

Vowel Long Short
a アースaasu (Earth) アスasu (tomorrow)
i チーズchiizu (cheese) チズchizu (map)
u プールpuuru (pool) プルpuru (pull)
e ステーキsuteeki (steak) ステキsuteki (lovely)
o ロースroosu (pork loin) ロスrosu (loss)

One important thing to note aboute the long-vowel mark, is that it should be written as a straight vertical line when writing vertically as shown below.

ハンバーガーhanbaagaa(hambuger)

Besides the long-vowel mark, some words, such as those using digraphs that end in "u" may use ウu to extend the vowel like with Hiragana.

And that's pretty much it for the long-vowel mark! Much easier compared to Hiragana's long vowels, no?
