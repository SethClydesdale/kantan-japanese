Kanji Dictionary


Welcome to the Kanji Dictionary! This page contains kanji from Kantan Japanese's lessons and the jouyou kanji list. Using the search bar below, you can quickly look up and review kanji that you're unfamiliar with or are having trouble memorizing. Hover over a kanji to see one of its basic meanings or click on a kanji to bring up more information on it. Lastly, if you'd like to practice specific kanji in an exercise, you can do that with our exercise editor here.


Quick Search

Our quick search looks for any instance of your query. For example, "cat" will also match "catch" in addition to "cat" and other similar entries. We also have some advanced search operators that you can use to filter kanji:

  • strokes:NUMBER will return kanji that have the amount of strokes you specify. For example, strokes:5 returns all kanji with only 5 strokes.
  • jlpt:NUMBER will return kanji of a specific JLPT level. For example, jlpt:5 returns all N5 (beginner) kanji.
  • genki shows all kanji that appear in the Genki textbooks.
  • quartet shows all kanji that appear in the Quartet textbooks.
  • tobira shows all kanji that appear in the Tobira intermediate textbook.
