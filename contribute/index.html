Contributing Bug/Typo Fixes

If you found a bug or typo on Kantan Japanese, please click the button below to let us know about it. Your reports help us to improve our website, so we greatly appreciate them, no matter how minor!

Contact Us

If you would rather fix the bug or typo yourself, however, you are more than welcome to! Just follow the steps below to learn how you can fix a bug or typo and submit it to us.

  1. To start, you first need to create a GitHub account.
  2. Once you've created your account, navigate to our repository and fork it. (Click here to learn about forking)
  3. Once forked, you can edit any of the files in your forked version of our repository. So the next step is to navigate to the file you want to edit and click the  icon to edit it.
  4. When you're finished editing the file, click Commit changes to save them.
  5. When you're finished fixing any bugs or correcting typos, the next step is to make a pull request in our repository. (Click here to learn about pull requests)
  6. Tell us what you changed in your pull request and then submit it.
  7. Now just wait for us to review it!
  8. If everything looks good, we'll merge it right away! If not, we'll let you know why.

That's all you need to know! If you have any questions about this process or anything else, please don't hesitate to reach out to us for help via the contact page. We appreciate your help and look forward to working with you!
